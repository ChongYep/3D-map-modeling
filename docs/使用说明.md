# 长征 · 数字沙盘｜使用说明

## 打开

双击仓库根目录的 `index.html`，用 Chrome / Edge 打开即可。文件已包含全部地图、地形和照片，**不需要联网**。

- 文件约 7.3 MB，第一次打开会有 2–5 秒的加载页（`1934—1935` + 进度线），加载完自动淡出。
- 拷到教室电脑、U 盘、微信文件传输都可以直接打开；不要只拷截图，截图不能交互。

## 课堂操作

| 操作 | 效果 |
| --- | --- |
| 点击地图上的站点标签 / 底部时间轴节点 | 镜头俯冲约 1.15 秒，然后进入该站全屏信息页 |
| 信息页 `‹ 上一站` / `下一站 ›`、`←` `→` | 在同一层里切换 8 个站点 |
| `Esc` / `← 返回沙盘` / 右上 `×` | 回到三维沙盘 |
| `空格` | 播放 / 暂停路线推进 |
| 左侧「行程节点 · 8 站」 | 展开或收起站点列表 |
| 鼠标拖动 / 滚轮 | 旋转、缩放沙盘 |
| 右下「夜 / 晨 / 红」 | 切换夜色 / 晨光 / 赤色纪念三套主题（会记住选择） |
| 右下「省名」 | 显示 / 隐藏省级行政区名称（共 34 个；窄屏会自动避让重叠，选择会记住） |
| 左下「薛岳部追击路线」 | 显示 / 隐藏国民党中央军薛岳部的蓝色追击路线（默认显示，选择会记住） |
| 左下「途中事件点」 | 显示 / 隐藏 6 个长征途中次级事件点；悬停看名称，点击看说明（默认显示，选择会记住） |
| 右下「投影」或按 `P` | 投影模式：隐藏统计、站点列表、数据卡、图例、署名，只留标题、地图和时间轴，画面略提亮 |
| 「导览」 | 自动依次讲解 8 站，每站停留约 7 秒，`Esc` 停止 |

右上数据卡会随路线进度显示**当前海拔**，下方是整条路线的海拔剖面；总里程与剩余百分比仍看底部时间轴。

薛岳部追击路线按**主要节点复原**（1934.10 赣南—1935.6 西昌），与红军主线同一精度：关键节点连线，不是逐日行军轨迹；川南各纵队的多次分进做了合并，湘江和大渡河等地地方军的封锁未单列，讲课时建议配合口头说明。

8 个主站之外，另有 6 个**途中次级事件点**（通道转兵、黎平会议、强渡乌江、巧渡金沙江、懋功会师、腊子口战斗）：路线上的小菱形，悬停看名称，点击出小卡，不占底部时间轴。

投屏建议：1920×1080、浏览器 `F11` 全屏，讲解前先按 `P` 进入投影模式。

## 局域网 / 公网分享（可选）

同网段（同一 Wi-Fi）分享，在仓库根目录运行：

```powershell
node scripts/serve-demo.mjs     # 然后同网段设备访问 http://<本机内网 IP>:5201/
```

正式对外发布可直接启用 GitHub Pages（仓库根目录即成品），或把根目录 `index.html` 放到任意静态托管。单文件约 7.3 MB，公网首屏受上传带宽限制，**讲解前先在目标设备上打开一次**。

## 史料与素材

- 史实依据：《中国共产党简史》（人民出版社，2021）；《中共中央关于党的百年奋斗重大成就和历史经验的决议》。
- 地形：AWS Open Data Terrain Tiles（SRTM / GMTED 等公开高程数据）。
- 站点照片为公开网络实景图片，页面内已标注拍摄地与图源，**仅供课堂展示**；公开发布前请确认授权并保留署名。

更详细的实现说明见 [`DEVELOPMENT.md`](DEVELOPMENT.md)。
