# 长征 · 数字沙盘 · 开发文档

课堂展示用的 Three.js 单文件网页。仓库根目录的 `index.html` 是可直接打开的单文件成品；可维护源码在 `../app/`，展示截图在 `screenshots/`。

- `../index.html`：单文件成品，双击浏览器打开即可离线运行
- `screenshots/01-全路线.png` / `02-遵义会议.png` / `03-松潘草地.png` / `04-地形立体视角.png` / `05-追堵态势.png` / `06-途中事件.png`：1920×1080 展示截图（02/03 为全屏信息页，05 为西南近景双线对比，06 为途中事件小卡）

## 构建

```bash
cd app
npm ci
npm run build:demo   # vite build + 复制到 ../index.html
```

- 只构建不复制：`npm run build`，产物在 `app/dist/index.html`。
- 单文件约 7.34 MB（gzip 后约 4.77 MB；照片、高程图、GeoJSON 与省名层全部内联）。
- 根目录 `index.html` 不依赖网络和本地文件，可直接发给别人或拷到教室电脑上打开。

需要重新生成地形素材时（改了投影取景、配色或分辨率）：

```bash
cd app
node bake-terrain.mjs   # 首次需联网下载 AWS Terrain Tiles，缓存到 terrain-tiles/
```

本地预览：

```bash
cd app
npm run dev        # 源码调试（Vite 默认端口）
node server.js     # 构建后的 app/dist，http://127.0.0.1:5199/
cd ..
node scripts/serve-demo.mjs   # 根目录单文件成品，http://127.0.0.1:5201/
```

## 交互

- 点击地图站点或底部时间轴：相机先俯冲约 1.15 秒，落地后淡入全屏信息页
- 信息页：左侧日期/标题/要点/正文/历史意义，背景为该站实景照片；右侧保留定位小图与图源
- 信息页左下：`‹ 上一站` / `下一站 ›` 与页码 `03 / 08`，左上：`← 返回沙盘`，右上：关闭；Esc 同样返回
- 信息页内 `← / →` 直接切换上下站；回到沙盘后 `← / →` 切换站点并重新俯冲
- 空格：播放 / 暂停路线；点击时间轴节点：进入对应信息页
- 左侧「行程节点 · 8 站」：展开/收起站点列表，整行可点击
- 右下「夜 / 晨 / 红」：切换场景配色，选择会记住（localStorage）
- 右下「省名」：显示 / 隐藏 34 个省级行政区注记，选择会记住（localStorage）
- 左下「薛岳部追击路线」：显示 / 隐藏国民党中央军薛岳部的追击路线（默认显示，选择会记住）
- 左下「途中事件点」：显示 / 隐藏 6 个长征途中次级事件点；悬停看名称，点击看小卡（默认显示，选择会记住）
- 右下「投影」或按 `P`：投影模式，隐藏统计、站点列表、数据卡、图例与署名，只留标题、地图与时间轴，画面略提亮；再按一次退出
- 左下：分层设色图例、指北针、随缩放实时换算的比例尺
- 调试参数：`?t=0.5`（路线进度）、`?still=1`（数字定格、关闭自动旋转，出图用）、`?play=1`、`?node=2&fly=1`、`?top=1`（俯视）、`?theme=dawn|night|crimson`、`?pursuit=0|1`（薛岳部追击路线开关）、`?waynotes=0|1`（途中事件点开关）、`?tour=1`（自动导览）

## 实现要点

- 投影：**阿尔伯斯等积圆锥投影**（25°N / 47°N 双标准纬线，105°E 中央经线），`albers()` 算出平面坐标后，用大陆（lat ≥ 17°）的包围盒自动求缩放与中心，`project()` 输出世界坐标 `(x, z = -y)`，北在 `-z`。
- **真实 3D 地形**：`bake-terrain.mjs` 用 AWS Terrain Tiles（Terrarium 编码，约 2 km 分辨率）取中国区域高程，在阿尔伯斯投影空间重采样成 `terrain-height.png`（640×552）。运行时把高程图解码成高度场，先做一遍 1-2-1 可分离平滑（去掉 DEM 细碎噪声在 480 网格上的竖向条纹），再按 **480×414** 网格位移出立体地形（0–9000 m 映射到约 5 个场景单位，约 52 倍垂直夸张），并用 **高程顶点色** 做分层设色（绿→黄→棕→雪白）；光照来自场景灯光与真实法线，因此陡坡不会出现贴图拉伸。
- **等高线**：在每 1000 m 的高程面上用 marching squares 逐格求交，贴地抬高绘制，强化山体的层次读感。
- **陆地裁剪**：在还原尺寸的 2D canvas 上把省份轮廓栅格化成陆地遮罩（**4096 px 宽、3 px 模糊**），地形材质用 `alphaMap + alphaTest` 按世界坐标裁到中国轮廓内；外缘另做一圈“侧裙”补到沙盘底座，低角度观察也是完整的立体版图。
- 轮廓与省界：`china-outline.json` / 省界折线逐点采样地形高度后贴地绘制，国界提亮、省界压暗；南海诸岛按中国地图惯例收进右下角小图（200×230）。
- 路线：按真实途经点串联 21 个坐标（瑞金 → 于都 → 湘江 → 通道 → 黎平 → 乌江 → 遵义 → 赤水 → 曲靖 → 皎平渡 → 会理 → 安顺场 → 泸定 → 夹金山 → 懋功 → 松潘草地 → 腊子口 → 哈达铺 → 榜罗镇 → 环县 → 吴起），先做 3 轮 **Chaikin 切角**再用 `CatmullRomCurve3` 插值，并沿地形高度贴地；`TubeGeometry` 绘制主线、暗色包边和光晕。吴起以东另有虚线 + 星标标注延安落脚点。
- 标签：`CSS2DRenderer`；外层 `.lbl` 是锚点，内层 `.lbl-box` 用 `--lx/--ly` 做**屏幕像素**偏移（`EVENTS[i].labelPx`），缩放地图时标签与节点的间距保持不变、也不会在密集区叠字。
- **省名层**：34 个省级行政区注记（23 省、5 自治区、4 直辖市、2 特别行政区）常驻在节点标签之下，颜色更冷、字号更小、无边框，形成“地形 → 省名 → 路线”的层级。锚点手工落在辖区内，并避开了 8 个史实节点；北京 / 天津 / 上海 / 香港 / 澳门 / 海南 辖区过小，用 `dx/dy` 屏幕偏移 + 引线挑到海面或邻省上空，圆点指回辖区。每 90 ms 用 `getBoundingClientRect` 做一次屏幕空间避让：先占住 8 个节点标签与“延安”，再按小辖区优先的顺序放置省名，重叠时淡出而不是叠字；右下「省名」可整体开关。
- **薛岳部追击路线**：蓝色实线管线（暗色包边 + 冷色光晕，比红军主线细一档），按薛岳部有明确记载的主要节点复原：石城—于都—赣州—郴州—衡阳—零陵—芷江—镇远—贵阳—遵义—茅台—毕节—曲靖—昆明—皎平渡—会理—西昌（1934.10—1935.6）。与红军主线同一精度：关键节点连线，不是逐日行军轨迹；川南各纵队的多次分进做了合并，未逐条单列，湘江、大渡河等地方军封锁也未单列。末端有蓝色标签「薛岳部追击」；默认显示，左下角图例里的「薛岳部追击路线」可开关并记忆选择。
- **途中事件点**：6 个次级事件（通道转兵、黎平会议、强渡乌江、巧渡金沙江、懋功会师、腊子口战斗）以小菱形挂在红军路线上，不占 8 站时间轴、不做全屏页。悬停出名称/日期，点击出约 262px 的小卡；小菱形每 90 ms 与 8 个主站标签、延安、薛岳部标签和已显示省名做屏幕避让，避免压字。左下角图例「途中事件点」可整体开关，默认显示。
- **俯冲 + 全屏信息页**：
  - 点击站点后先把上一张信息页淡出，相机按当前方位俯冲到 `0.62 × CAM_DIST`，FOV 不变，1.15 秒缓动；
  - 飞行动画结束的回调里再打开信息页，所以俯冲过程不会被遮挡；
  - 信息页背景是该站实景照片 `object-fit: cover`，用 `object-position` 为每站单独取景；左侧叠一层从深到透明的横向渐变保证文字可读，照片右侧保留完整画面；
  - 信息页内容复用原卡片 DOM，改为全屏布局：左侧 660px 信息栏、右侧定位小图与图源；图片、日期、标题、要点、正文、历史意义、出处全部保留；
  - 打开时背景照片从 1.02 缓慢推到 1.075（16 秒），左侧文字轻微右移淡入；关闭时反向淡出；
  - 信息页内 `上一站/下一站` 不重新俯冲，只更新内容；从沙盘点击则完整走“俯冲 → 落地 → 页面”；
  - 每站图片在俯冲开始时就设置 `img.src` 预加载，页面出现时通常已就绪。
- 信息层：
  - 时间轴进度行显示“已行进 X 里 / 剩余 Y% / 第 N/8 站”，里程按路线长度线性映射到 25,000 里；
  - 右上数据卡显示**当前海拔**、当前站点，并绘制 **沿途海拔剖面**（沿路线采样 DEM，真实数据，标注最高点）；大数字与剖面联动，播放时随行军位置实时变化，不再和底部时间轴重复显示里程；
  - 信息页右下角定位小图（全国轮廓 + 整条路线 + 当前站点）；
  - 相机默认 1.72 × 版图高。
- 播放/导览：`progress` 用 `playStart/playFrom` 绝对计时；导览复用 `selectEvent`，每站 6.8 秒，Esc / 点击地图 / 空格 / 返回沙盘都会立即停止。
- 主题：CSS 变量 + 场景背景/雾/半球光/主光/补光/轮廓线/路线/地形染色的整套切换，三套主题（夜、晨、红）。
- **展陈化（美化包）**：
  - 字体与版式：主标题与信息页标题改用宋体族（`--serif`：Noto Serif SC → 思源宋体 → 宋体），标题前加金色竖线，统计数字用等宽字形；整体更像展陈海报而非仪表盘。
  - 地图质感：国界线用冰蓝发丝线（0x93c2de，opacity 0.9），沙盘侧裙外缘再描一圈暖金边（0xffb066，opacity 0.38），底部加一层低透明度暖金地面辉光补光；站点标签带 `01`–`08` 编号角标，并按下标像素偏移自动算出引线长度（`--lbl-line`），当前站点标签切换为金色高亮。
  - 信息页版面：四角细框、左下巨型年份水印（随站点年份更新）、右侧竖排英文侧标、右上朱红「长征」印章、底部 8 站进度点条；图源拆成“拍摄地”与“史实依据”两行。
  - 转场与质感：加载页（1934—1935 / 标题 / 扫描线，首帧渲染完成后淡出）、俯冲白闪、全屏颗粒噪点（opacity 0.035）削弱大色块的数码感；`prefers-reduced-motion` 下自动关掉这些动画。
  - 主题化：三套主题的遮罩基色 `--veil-rgb` 同步到信息页背景、按钮与来源条，切主题时信息页不会发灰。
  - 投影模式：`P` 或右下「投影」隐藏统计、站点列表、数据卡、图例、署名与操作提示，只留标题、地图、时间轴，画面 brightness 1.07 / contrast 1.03 微调，适合教室投屏。
- 信息页图片：8 张实景照片，照片右下与信息页出处行都标注了拍摄地/图源；窄屏内容可滚动。

## 数据与素材

- 省界：阿里云 DataV 公开 GeoJSON（`china.json`）。
- 国界：同一来源的全国国界（`china-outline.json`，从 DataV `100000.json` 取得），保证与省界顶点一致。
- 地形：AWS Open Data **Terrain Tiles**（Terrarium 编码，底层为 SRTM、GMTED、ETOPO1、NED 等公开高程数据），页面底部已标注来源；`bake-terrain.mjs` 只取中国区域、重投影并重新设色。
- 信息页照片（均为实景）：瑞金叶坪旧址（青海新闻网）、湘江战役纪念馆、遵义会议会址（遵义日报）、赤水丙安古镇、泸定桥、夹金山（新华社）、松潘草地、吴起中央红军长征胜利纪念园；来自新华网、遵义日报、青海新闻网、百度百家号及公开网络图片，**仅供课堂展示**；公开发布前请向对应机构确认授权并保留署名。
- 史实依据：《中国共产党简史》（人民出版社，2021）；《中共中央关于党的百年奋斗重大成就和历史经验的决议》。信息页底部已注明。

## 已知限制

- 地形是**由高程图实时生成的 3D 网格**（480×414），不是测绘级 DEM；如果改动投影参数或地图取景（`FIT`），需要重新跑 `bake-terrain.mjs`，否则地形会和边界错位。
- 垂直方向做了约 52 倍夸张（便于观察山脉与高原），山体细节约 2 km 分辨率，适合投屏讲解，不是精确地形测量。
- 低角度、极近距离看海岸/高原边缘时，陆地遮罩的栅格边缘仍可能有轻微锯齿（已把遮罩提高到 4096 px 并做 3 px 羽化）。
- 信息页背景图已换为 1920×1080 / 2400×1350 的高清图（赤水站源图 1707×1280，约 1.1 倍），全屏基本 1:1，不再有明显放大发虚。
- 信息页是“实景照片 + 文字”的版面，不是 360° 全景，不能环顾；如需街景式浏览，需要另拍/另找 8 组 360° 素材。
- 夹金山（新华社）保留原始 XINHUA NEWS 水印（页面右下定位小图会遮住一部分），图注已标注新华社；其余站点已换为无可见水印的高清图。
- 路线是关键节点连线，不是逐日行军轨迹；里程读数是按路线长度线性换算的示意值，如需更精确可往 `ROUTE` 里补途经点或按日期标定。
- 页面按 1920×1080 投屏设计；≤1180 px 收起数据卡、站点列表与图例，≤820 px 另外收起署名，信息页改为上下布局并可滚动（手机上是“照片在上、文字在下”的长页，需下滑看资料来源）。
- 省名层会随窗口宽度和视角自动避让：窄屏或密集视角下，重叠的次要注记会暂时淡出，以保证 8 个节点标签始终可读；默认视角下 1920×1080 及以上可显示全部 34 个省名。
- 薛岳部追击路线是按**主要节点复原**的作战路线，不是逐日行军轨迹，也不是所有国民党军：川南各纵队的多次分进做了合并，湘江与大渡河等地地方军的封锁未单列。真实历史中没有一支国民党军从江西一路追到陕北；薛岳部最远到西昌，继续北上的堵截由川军、东北军等担任。若要做严格军事史地图，应改为多段箭头并逐段标注部队与日期。
- 单文件 7.3 MB（gzip 4.76 MB）是离线可用的代价：局域网/本机打开很快，公网共享受上传带宽限制。
- 信息页照片为网络公开图片，仅供教学使用，版权归原作者/机构。

## 回归检查

构建后启动 `app/server.js`（被测 `app/dist`，5199 端口），或根目录 `scripts/serve-demo.mjs`（被测根目录成品，5201 端口），再运行：
